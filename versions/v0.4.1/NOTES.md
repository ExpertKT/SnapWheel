# SnapWheel v0.4.1

**日期**：2026-09-12

## 本次更新
- **轮盘上做了真·毛玻璃**：分层窗口用不了系统 acrylic（会给整个窗口矩形蒙灰），所以改成自己抓背景 —— 显示之前把轮盘背后那块屏幕截下来、缩到 1/6 做两轮盒式模糊再放大回去，画面板时裁进形状里再叠玻璃色。透过去的是真桌面；面板还压了一层黑保证任何背景上字都清楚
  - 抓取时机：每次显示前抓一次、隐藏后补抓一次（保证下次是新背景）；换角落/改尺寸会重新抓
  - 玻璃底随「玻璃不透明度」变（越低越透），纯扁平风格下自动关闭
- **托盘叫出轮盘也播开启动画**（托盘菜单/双击/第二个实例唤起/热键都走同一套），和首次启动完全一样
- **指针停在万能键上有反应**：放大 4.5% + 外发光变亮变大 + 内芯点亮，按下再叠一层（都有缓动）
- **点「项目1」药丸直接改名**：悬停时药丸变亮并在右边提示「点一下改名」，点开小输入框，回车即改；名字会立即写盘
- 新增测试：模糊管线方差校验（16256 → 6）+ 真背景抓取校验；两个变体各 95 项
