# SnapWheel v0.3.1

**构建方式**：普通构建（完整版 · 含万能键）

## 本版修复
### 1. 缩放/移动「只能拖一点」—— 已修
移动时的边界夹取原先用**外接圆半径**（`√(hw²+hh²)`）：选区一大，这个半径甚至超过屏幕，导致中心被钉死，只能挪一点点。
现在改为按**外接矩形**夹取 → 无论选区多大都能自由移动；选区比屏幕还大时自动居中。

### 2. 缩放后「乱飞」—— 已修
在**选区之外**松开鼠标时，`_resizeCorner / _rotating / _moving / _dragging` 状态没有被清除，之后**任何鼠标移动都会继续缩放或旋转**，于是“一通操作就乱飞”。
现在 `OnMouseMove` 里加了保护：**一旦检测到左键其实没按住，立即清空所有拖拽状态**。

### 3. 缩放本体（沿用 v0.3.0 修正）
- **对角绝对固定**，不再出现“拖右下角、上边跟着动”；
- 锁定比例时缩放稳定；
- 只在屏内限制尺寸，不移动固定角。

## 本版新增
### 4. 右上角尺寸输入面板
- 屏幕**右上角**新增信息面板：**宽 / 高 输入框 + 「应用」按钮**，可直接输入像素尺寸（自动限制在屏幕内；锁定比例时按比例联动）。
- **「角度归零」按钮**：一键把旋转角度重置为 0°。
- 面板下方实时显示**当前角度**与比例锁定状态。
