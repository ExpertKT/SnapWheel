# SnapWheel v0.5.2

**日期**：2026-09-13

## 本次更新
动画性能大优化：分层缓存（环+控件稳态整块贴图）+ 1:1 贴图绕开双三次重采样 + 卡片阴影/玻璃底/描边贴片 + 缩略图不再每帧从原图重缩 + 玻璃换底交叉淡入整帧只混一次。他真实 125% 屏幕实测：开启动画 7.9ms、收起 15.6、滚动 10.0、悬停放大 14.5、玻璃换底 16.3、切盘闪光 9.4，全部每帧 ≤20ms 且无 >40ms 帧。另含 v0.5.1 的撤销删除（后悔药）与标注工具条四方向摆放。★ 无万能键线到 v0.2.22 为止，之后不再更新。
