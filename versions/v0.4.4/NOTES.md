# SnapWheel v0.4.4

**日期**：2026-09-12

## 本次更新
- **分辨率 / DPI 适配**：以前所有尺寸都是写死的物理像素，2K/4K 或不同缩放比例下大小就不对了
  - 改成整块轮盘按一个系数等比缩放：绘制统一走 ScaleTransform，字体、图标、线宽、间距全跟着放大，命中测试也统一换算到逻辑坐标
  - DPI 感知从「系统级」升级到「**每显示器 v2**」（多屏不同缩放时不会被拉伸糊掉），并响应 WM_DPICHANGED
  - 新增设置项「**界面缩放**」：自动（按显示器 DPI，2K@125% → 1.25、4K@150% → 1.5）/ 80% / 90% / 100% / 110% / 125% / 150% / 175% / 200% / 250%
  - 自动模式不会把轮盘撑得比屏幕还大；手动模式窗口也封顶到屏幕尺寸
  - 缩略图按物理像素生成（缩放后不发虚）；截图浮层的手柄、比例胶囊、右上角宽高面板和字号也按 DPI 放大
  - 新增缩放适配测试：0.8/1.0/1.25/1.5/2.0/2.5 六档下窗口尺寸、键位、命中区域全部一致（两个变体各 115 项）
