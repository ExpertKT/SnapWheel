# SnapWheel v0.4.3

**日期**：2026-09-12

## 本次更新
- **修「确定/取消」按钮四角显示错误**：圆角外的底色原来取 Parent.BackColor，而对话框背景是半透明毛玻璃（A<255）取不到就退回纯白，于是四角闪白块 —— 鼠标划过触发重绘才恢复、重开又复现。现在取整个窗体（连 alpha）的底色，并且每个弹框显示后强制整窗重绘一次
- **轮盘毛玻璃调强**：面板底色透明度整体下调（卡片 232→206、药丸 214→192、圆钮 206→188），模糊从 2 轮盒式加大到 3+3+2，默认「玻璃不透明度」80 → 55 —— 现在能明确看出背后的桌面被糊在面板里
- **对话框毛玻璃收敛**（原来太猛）：acrylic tint 190 → 232、窗体底色不透明度 228 → 240，字更清楚、玻璃只在边缘透一点
- 测试：完整版与 NO_KEY 各 101 项、缩放 ALL PASS、格式 52、拖放 19
